# 🔗 Link in Bio – Sergio Coitiño

Proyecto **Link in Bio** desarrollado para centralizar mis principales enlaces profesionales en una sola página, ideal para usar en redes sociales como Instagram, LinkedIn o portfolios personales.

La página funciona como una tarjeta de presentación digital, con un diseño limpio, minimalista y totalmente responsivo.

---

## 🚀 Demo en vivo

👉 https://sergio-coitino.netlify.app/

---

## 📌 Características

- 📱 Diseño **responsive** (mobile-first)
- 🎨 Interfaz minimalista y clara
- 🔗 Enlaces directos a redes y portfolio
- ⚡ Carga rápida (HTML + CSS puro)
- 🌐 Ideal para usar como *Link in Bio*

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **Google Fonts (Poppins)**
- **Font Awesome** (iconos)
- **Netlify** (deploy)

---

## 📂 Estructura del proyecto

```
/
├── index.html        # Estructura principal de la página
├── style.css         # Estilos y variables (light / dark mode)
├── theme.js          # Lógica del cambio de tema (dark mode)
└── img/
    ├── profile.jpeg  # Imagen de perfil
    └── icon.png      # Favicon

```

## 📌 Uso recomendado

Este proyecto puede utilizarse como:
- Link principal en la bio de Instagram
- Tarjeta de presentación digital
- Página de contacto rápido
- Complemento de un portafolio profesional
